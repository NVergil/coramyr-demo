# Coramyr Demo - Landing Page Médica

Prototipo de Landing Page estática diseñada para una doctora o profesional de la salud. El proyecto destaca por un enfoque minimalista, formal y altamente responsivo.

## 🚀 Tecnologías Utilizadas

- **React:** Librería principal para la interfaz de usuario.
- **Vite:** Herramienta de compilación para un desarrollo ágil y rápido.
- **Tailwind CSS (v4):** Framework de utilidades CSS para los estilos, layout y responsividad.
- **Lucide React & SVGs:** Para la iconografía médica y de redes sociales.

## ✨ Características Principales

1. **Diseño Responsivo:** Completamente adaptable a pantallas de móviles, tablets y monitores de escritorio.
2. **Componentes Modulares:** Todo está estructurado en una sola página (Single Page Application).
3. **Secciones Integradas:**
   - **Hero / Sobre Mí:** Presentación inicial con imagen de perfil y call-to-action (CTA).
   - **Especialidad:** Grid descriptivo con los servicios médicos ofrecidos.
   - **Testimonios:** Carrusel estático de comentarios de pacientes.
   - **FAQ (Preguntas Frecuentes):** Panel estilo acordeón para resolver dudas comunes.
   - **Footer:** Información de contacto y accesos directos a redes sociales (Facebook, Instagram y TikTok).

## 🛠️ Instalación y Ejecución Local

Para visualizar este prototipo en tu entorno local, sigue estos pasos:

1. Clona este repositorio:
   ```bash
   git clone https://github.com/NVergil/coramyr-demo.git
   ```
2. Navega al directorio del proyecto:
   ```bash
   cd coramyr-demo
   ```
3. Instala las dependencias necesarias:
   ```bash
   npm install
   ```
4. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
5. Abre en tu navegador la dirección (normalmente `http://localhost:5173`) para ver el proyecto en vivo. Para verlo en tu celular, puedes usar `npm run dev --host` si ambos dispositivos están en la misma red Wi-Fi.
